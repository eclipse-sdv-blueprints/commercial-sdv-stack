# ODX generation for PoC

This is a modification of the [Eclipse OpenSOVD](https://github.com/eclipse-opensovd) [classic-diagnostic-adapter](https://github.com/eclipse-opensovd/classic-diagnostic-adapter)(CDA) [testcontainer](https://github.com/eclipse-opensovd/classic-diagnostic-adapter/tree/main/testcontainer) ODX generation setup, specifically creating Powertrain diagnostic services for use with the `powertrain-mode-controller` uService.

The entry point for this is the `generate.py` script, with some subsequent modifications to related code.

## Managing MDD files

The ODX/PDX generated by the Python scripts in this folder can be converted to the MDD format, which is what the `classic-diagnostic-adapter` works with. To perform the conversion, you need the `odxtools` binary (also from the OpenSOVD project).

To manually generate MDD files, run the following commands (this step is only necessary when changes to the ECU database have been made):

```sh
# Generate ODX files
cd odx
./generate_docker.sh
cd ..

# Convert PDX to MDD (you need to have previously built the converter)
cd odx
java -jar <path-to-odx-converter>/converter/build/libs/converter-all.jar blueprint-ecu.pdx
cd ..
```
